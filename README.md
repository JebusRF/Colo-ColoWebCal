# Colo-Colo WebCal ⚪⚫🏆

Calendario automático de Colo-Colo para:

- Primera División
- Copa Chile
- Libertadores
- Sudamericana
- Supercopa
- Amistosos

Compatible con:

- Apple Calendar
- Google Calendar
- Outlook

## Suscribirse

### iPhone / iPad

Abrir en Safari:

webcal://...

### Google Calendar

Agregar calendario desde URL:

https://...

### Outlook

Agregar calendario desde Internet:

https://...

## Actualización

El calendario se actualiza automáticamente desde ESPN.
